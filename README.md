# Badminton Backend (bedminton-be)

## Overview
This repository contains the backend for the Badminton application.

## Getting Started

### Running the Application
To start the application, run:
```sh
./start
```

### MacOS Permission Issue
If you encounter a permission issue while trying to run the script on MacOS, execute the following command first:
```sh
chmod +x ./start.bat
```

Then, retry running the start command:
```sh
./start
```

## Requirements
Ensure Docker is installed on your machine before running the application.
